LESSON 01 / 上手 · 15 分钟

先得到第一张 PDF

LaTeX 把文本文件编译成 PDF。你在源文件里标记“这是标题、这是公式”，编译器负责编号和排版。对准备考研的 ECE 学生，最划算的用途是写带推导的笔记、整理实验数据、复用报告模板。备考做题仍以你能快速推导和订正为准；老师指定提交 Word 时遵循课程要求。

  1. 在 Overleaf 创建空白项目（Blank Project），打开 main.tex，将其内容全部换成下面的示例。
  2. 在项目设置中找到 Compiler，选 XeLaTeX，确认主文档为 main.tex，点击 Recompile。
  3. 右侧 PDF 应出现标题、姓名、日期、实验目的和一行公式。把作者换成自己，再编译，最后下载 PDF。
完整文件 · 可单独编译
\documentclass[UTF8,fontset=fandol,a4paper,12pt]{ctexart}
\usepackage{amsmath}
\title{我的第一份实验记录}
\author{你的名字}
\date{\today}

\begin{document}
\maketitle
\section{实验目的}
观察两个单位向量的夹角如何影响点积。

当夹角为 $60^\circ$ 时，点积为 $\cos 60^\circ=0.5$。
\end{document}

第一行选择中文短文文档类；fontset=fandol 明确使用 TeX 发行版可提供的中文字体。文档类到正文开始之间叫导言区，负责加载功能和设置。标题命令保存信息，\maketitle 才把它放上纸面。

本 HTML 可离线阅读，网页里的按钮用于复制或下载源码。得到真正的 PDF，需要在线编译器或已安装的本地 TeX 环境。

LESSON 02 / 环境 · 可选

在 Windows 本地编译

想用 Git 留存实验报告、断网写作时，再装 TeX Live。编辑器负责写文件，XeLaTeX 负责排版，latexmk 会按需反复运行编译器和文献工具。

  1. 从 LaTeX 官方入口进入 TeX Live 的 Windows 安装说明。完整发行版省去逐个寻找中文字体和宏包的工作。安装后重开 PowerShell。
  2. 新建文件夹，把上一节下载的 main.tex 放进去，用 UTF-8 保存。在这个文件夹里打开终端。
  3. 依次执行下面的命令。若前两条报告找不到命令，先检查安装是否完成、终端是否重开，再检查安装程序显示的 bin 目录是否在 PATH。
PowerShell · 依次运行
xelatex --version
latexmk -v
latexmk -xelatex -interaction=nonstopmode -file-line-error main.tex

打开同目录的 main.pdf。源文件和用到的图片、文献库要保留；.aux 存引用信息，.log 记编译过程。Git 中优先提交源文件、图片和文献库。只有模板明确要求时才更换编译引擎。

LESSON 03 / 基础 · 命令与环境

写出有层次的正文

命令以反斜杠开头。花括号装必需参数，方括号通常装可选参数。环境用同名的 begin 和 end 包住内容。下面的片段放进第一节示例的正文区，保留原有文档外壳。

正文片段
\section{实验方法}
\subsection{记录条件}
固定输入大小，记录编译器版本。这里是\textbf{控制变量}。

空一行开始下一段。源文件里普通的单次换行通常不会另起一段。
\begin{enumerate}
  \item 预测输出。
  \item 编译运行，并把结果记入表格。
\end{enumerate}
成功率为 95\%，文件名为 \texttt{mini\_kv.c}。
% 这一行是给自己的注释。

itemize 给出无序列表。把 \tableofcontents 放在标题之后可生成目录，重复编译以更新页码。星号版 \section*{致谢} 生成无编号标题，默认不会进入目录。正文中要打印 # $ % & _ { }，在前面加反斜杠；短文件名和命令也可写成 \verb|mini_kv.c|。

动手练习 把两步扩为三步，添加“分析差异”；让文件名中的下划线正确显示。
检查答案

新增一个 \item 分析差异。；文件名用 \texttt{mini\_kv.c}。没有数学含义的下划线别用数学模式绕过去。

LESSON 04 / 数学 · 推导与符号

把 ECE 公式写清楚

短变量放在行内，如 $R$；单独展示且无需编号的公式用 \[ ... \]。需要编号时用 equation，多行推导用 align。本章使用第一节已加载的 amsmath。

例一 · 一阶 RC 低通滤波器
令电阻为 $R$，电容为 $C$，角频率为 $\omega$。
\begin{align}
  H(j\omega) &= \frac{1}{1+j\omega RC}, \\
  |H(j\omega)| &= \frac{1}{\sqrt{1+(\omega RC)^2}} .
\end{align}
当 $\omega=1/(RC)$ 时，幅值为 $1/\sqrt{2}$。
第二行的排版示意|H(jω)|=11+(ωRC)2

& 标出各行对齐的位置，两个反斜杠结束一行。下标用 _，上标用 ^，多个字符要用花括号括住。\sin、\log 会把函数名排成正体。

例二 · 离散信号、分段函数与矩阵
\[
  X[k]=\sum_{n=0}^{N-1} x[n]\,e^{-j2\pi kn/N},
  \qquad
  u[n]=\begin{cases}1,& n\ge 0,\\0,& n<0.\end{cases}
\]
\[
  \mathbf{A}=\begin{bmatrix}1 & 2\\3 & 4\end{bmatrix},
  \qquad E=\int_{-\infty}^{\infty}|x(t)|^2\,dt .
\]
动手练习 写出截止频率 f 下标 c 等于 1 除以 2πRC。再为它加上编号。
检查答案

\begin{equation} f_c=\frac{1}{2\pi RC} \end{equation}。频率单位为 Hz；前一个例子中的角频率单位为 rad/s。

LESSON 06 / 系统 · 实验可复现

记录代码与运行条件

终端输出可放进 verbatim 环境原样展示；C 源码用 listings 宏包。代码里的百分号和下划线保留原样。下面的示例用 C99 或更新标准编译，输出本机的字节数。

导言区
\usepackage{listings}
正文 · 带行号的程序
\begin{lstlisting}[language=C,numbers=left,
  basicstyle=\small\ttfamily,breaklines=true,frame=single]
#include <stdio.h>
int main(void) {
    printf("%zu\n", sizeof(int));
    return 0;
}
\end{lstlisting}

已有 probe.c 文件时，可用 \lstinputlisting[language=C]{probe.c} 直接排入文件内容。报告中记录编译器版本、命令、输入和实际观察值；讨论写出哪个现象支持或反驳了预测。较长的原始日志可留作附件。

文献库 · 与下一节共用

biber main

LESSON 08 / 综合 · 可下载的完整工程

交付一份 CSAPP 实验报告

这个工程只需要两个文件。下载本节的 main.tex 和 refs.bib，放在同一个新目录；Overleaf 用户上传到同一个空白项目。在 XeLaTeX 下编译。示意图用原生排版生成，无需额外图片。

完整报告 · 系统实验 01
\documentclass[UTF8,fontset=fandol,a4paper,12pt]{ctexart}
\usepackage[margin=2.5cm]{geometry}
\usepackage{amsmath,booktabs,graphicx,listings}
\usepackage[backend=biber,style=numeric]{biblatex}
\addbibresource{refs.bib}
\usepackage[hidelinks]{hyperref}
\title{系统实验 01：观察数组的存储布局}
\author{姓名：\underline{\hspace{3cm}}}
\date{\today}
\begin{document}
\maketitle
\begin{abstract}
用 C 程序输出数组元素的地址和元素大小，用相邻地址的差检验数组布局。
表中的数值是演算示例，提交时请替换为自己的测量。
\end{abstract}
\section{问题与预测}
记元素大小为 $s$ 字节，首元素的字节地址为 $A_0$。
连续数组中，下标为 $i$ 的元素地址应满足式~\eqref{eq:address}。
\begin{equation}\label{eq:address}
  A_i=A_0+i\,s .
\end{equation}
有关机器级数据表示的背景参见文献~\cite{csapp3}。
\section{方法}
记录操作系统、编译器版本与编译参数，再运行以下程序。
\begin{lstlisting}[language=C,basicstyle=\ttfamily\small,frame=single]
#include <stdio.h>
int main(void) {
    int a[3] = {10, 20, 30};
    printf("size = %zu bytes\n", sizeof a[0]);
    for (size_t i = 0; i < 3; ++i)
        printf("%zu: %p\n", i, (void *)&a[i]);
    return 0;
}
\end{lstlisting}
\section{结果}
图~\ref{fig:array} 表示元素顺序，表~\ref{tab:offset} 给出示例偏移。
\begin{figure}[htbp]
  \centering
  \fbox{\strut $a[0]$}\fbox{\strut $a[1]$}\fbox{\strut $a[2]$}
  \caption{数组元素的排列示意}\label{fig:array}
\end{figure}
\begin{table}[htbp]
  \centering
  \caption{当元素大小为 4 字节时的示例偏移}\label{tab:offset}
  \begin{tabular}{rrr}
    \toprule
    下标 & 值 & 相对首地址的偏移（字节）\\
    \midrule
    0 & 10 & 0\\
    1 & 20 & 4\\
    2 & 30 & 8\\
    \bottomrule
  \end{tabular}
\end{table}
\section{讨论}
请填入实际测得的元素大小、三条地址和两次相邻地址差。
比较测量与预测，说明换成 \texttt{double} 后应如何修改预测。

\end{document}

动手练习 把数组元素改为 double。先预测相邻地址的差值，再运行并更新报告。
检查答案

LESSON 09 / 速查 · 从第一条错误开始

读懂报错，自己排查

先看日志中第一条错误及对应行号，同时检查上一行。一次只改一处。卡住时复制第一节能工作的最小文件，再逐段添回出错的内容。

看到的现象先做的检查
Undefined control sequence查报错行里反斜杠后的命令是否拼错。若是 top­rule 或 eqref，再核对是否加载 booktabs 或 amsmath。
Missing $ inserted先看正文有没有裸露的下划线，或数学公式的美元符号是否成对。
Runaway argument / File ended while scanning…向前查最近改动的花括号，尤其是标题、题注或分式的参数。
中文字体找不到或中文缺字确认编译器为 XeLaTeX、文件为 UTF-8，使用本教程的 ctexart 与 Fandol 字体配置；本地可用发行版管理器补装 ctex 和 fandol。
File … not found核对图片路径、扩展名、大小写；确认文件已上传，或者位于主文件所在项目中。
图表引用显示 ??核对标签拼写、唯一性及位置，重复编译。仍有问号时检查目标环境是否实际产生了编号。
文献表为空或显示引用键检查 refs.bib 文件名、引用键、逗号与花括号，运行 biber main，查看 .blg 日志，再运行 XeLaTeX 两遍。
Overfull hbox这是行太宽的警告。定位对应 PDF 行，检查长文件名、过宽代码或表格；给代码启用 breaklines，或缩短过长文本。
